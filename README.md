## Chip-8 Emulator (Written in C)

The Chip-8 is a virtual machine developed for creating simple games. It has 4KiB of memory and 16 8-bit registers. This program runs the Chip-8 emulator and allows the user to play games such as pong and Tetris. I used C for this project because it is a low-level systems language that allows me to manipulate the memory and registers directly.
